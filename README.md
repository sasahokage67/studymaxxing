# STUDYMAXXING // asianchangs

> **Maximum study. Minimum cheating.**
> Платформа устной защиты кода от слепого копирования из нейросетей и ИИ.

---

## ⚡ О проекте

**StudyMaxxing** решает проблему бездумного копирования кода из нейросетей (ChatGPT, Claude, DeepSeek):
1. **Загрузка кода**: Ученик загружает свой Python-код лабораторной или задачи.
2. **Анализ нейросетью**: ИИ анализирует ключевые развилки в коде (циклы, структуры данных, обработку ошибок) и формулирует 3 коротких прицельных вопроса именно по строчкам этого кода.
3. **15-секундный блиц**: Ученик включает микрофон и за 15–20 секунд устно объясняет логику решения. За это время невозможно отправить промпт в ИИ и прочитать чужой ответ.
4. **Акустический парсер и верификатор**: Речь ученика распознается в реалтайме с нормализацией Python-синтаксиса (`while True`, `int(input())`, `break`), а калиброванная модель выставляет оценку (85%+ — сдано без ручной проверки; <=65% — отправка на рецензию учителю; 0% — при признании незнания).
5. **Кабинет учителя и журнал**: Автоматический журнал оценок, аудиозаписи ответов, кастомные задания и таймеры.

## 🛠 Стек технологий

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Lucide Icons, JetBrains Mono & Inter typography
- **Speech Engine**: Web Speech API + JSGF Grammar Biasing + Cyrillic Phonetic Normalizer
- **State & Storage**: React Context + Persistent LocalStorage state management
- **i18n**: Русский, Қазақша, English

## 🚀 Быстрый старт

### 1. Клонирование и установка зависимостей
```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd learnproof
npm install
```

### 2. Запуск локального сервера разработки
```bash
npm run dev
```
Приложение откроется по адресу `http://localhost:3000/`.

### 3. Сборка для продакшена
```bash
npm run build
npm run preview
```
